En producción

Proyecto final DAM · Backend

Boutique Market

Sistema de gestión multi-tenant que usan a diario dos negocios familiares reales —un salón de manicura y una pollería—, con una API en Node.js y una base de datos aislada para cada uno.

  • Node.js
  • Express
  • PostgreSQL
  • JWT
  • Docker
Detalles técnicos
  • Aislamiento multi-tenant con AsyncLocalStorage: el contexto de cada negocio viaja con la petición, sin fugas de datos entre peticiones.
  • Seguridad por capas: JWT, bcrypt, cifrado AES-256, Helmet y rate limiting.
  • 44 endpoints REST documentados con Swagger, validación con Zod, tests con Jest + Supertest y entorno completo con Docker Compose.
